📌 规范路径与向后兼容旧路径

┌─────────────────────────────────────────────────────────────────────────────┐
│ 1️⃣  列表 Quizzes                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ GET /api/courses/:cid/quizzes                                               │
│ 学生看：已发布 + 可用的 | Faculty 看：全部                                    │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 2️⃣  创建 Quiz (Faculty only)                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ POST /api/courses/:cid/quizzes                                              │
│ Body: { title, description, questions, settings, ... }                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 3️⃣  获取 Quiz 详情                                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✨ 规范: GET /api/courses/:cid/quizzes/:qid                                 │
│ 🔄 兼容: GET /api/quizzes/:qid                                              │
│ 学生看未发布 → 403 Forbidden                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 4️⃣  编辑 Quiz (Faculty only)                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✨ 规范: PUT /api/courses/:cid/quizzes/:qid                                 │
│ 🔄 兼容: PUT /api/quizzes/:qid                                              │
│ Body: { title, questions, ... }                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 5️⃣  删除 Quiz (Faculty only)                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✨ 规范: DELETE /api/courses/:cid/quizzes/:qid                              │
│ 🔄 兼容: DELETE /api/quizzes/:qid                                           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 6️⃣  发布 Quiz (Faculty only)                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✨ 规范: POST /api/courses/:cid/quizzes/:qid/publish                       │
│ 🔄 兼容: POST /api/quizzes/:qid/publish                                    │
│ 设置: published=true, publishedBy=userId, publishedAt=now()                 │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 7️⃣  取消发布 Quiz (Faculty only)                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✨ 规范: POST /api/courses/:cid/quizzes/:qid/unpublish                     │
│ 🔄 兼容: POST /api/quizzes/:qid/unpublish                                  │
│ 设置: published=false, unpublishedBy=userId, unpublishedAt=now()           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 8️⃣  提交尝试 (Student/Faculty)                                                │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✨ 规范: POST /api/courses/:cid/quizzes/:qid/attempts                      │
│ 🔄 兼容: POST /api/quizzes/:qid/attempts                                   │
│ Body: { answers: [ {questionId, answer}, ... ] }                            │
│ 返回: { attempt, score, total }                                             │
│ 检查: 发布状态、尝试次数、计算评分                                              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 9️⃣  查看尝试列表 (Faculty=全部, Student=自己的)                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✨ 规范: GET /api/courses/:cid/quizzes/:qid/attempts                       │
│ 🔄 兼容: GET /api/quizzes/:qid/attempts                                    │
│ 返回: [ { _id, score, attemptNumber, createdAt, ... }, ... ]              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔟 查看单次尝试                                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ ✨ 规范: GET /api/courses/:cid/quizzes/:qid/attempts/:aid                  │
│ 🔄 兼容: GET /api/quizzes/:qid/attempts/:aid                               │
│ Faculty: 可查看任意 | Student: 403 if 不是自己的                              │
└─────────────────────────────────────────────────────────────────────────────┘

╔════════════════════════════════════════════════════════════════════════════╗
║ HTTP STATUS CODES                                                          ║
╠════════════════════════════════════════════════════════════════════════════╣
║ 200 OK              成功的 GET/PUT/DELETE/POST                            ║
║ 400 Bad Request     无效输入 (如"用户名已存在")                            ║
║ 401 Unauthorized    未登录 (缺少认证)                                      ║
║ 403 Forbidden       权限不足 (如学生试图发布、查看未发布或他人的)          ║
║ 404 Not Found       quiz/attempt 不存在                                    ║
║ 422 Unprocessable   业务规则违反 (如"超出最大尝试次数")                   ║
